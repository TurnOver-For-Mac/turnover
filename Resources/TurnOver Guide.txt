TurnOver: the guide

HOW TO USE TURNOVER

TurnOver is a screen reader for the Mac. It reads every app with its own voice and the keys you already know from
VoiceOver. One reader speaks at a time: while TurnOver is on VoiceOver is off, and when TurnOver is off VoiceOver reads.
This page is the short tour. Each section links to the guide that goes into detail.

Three things to remember

1. Command Control Comma is the way in to everything TurnOver: press it, hear "TurnOver", then a letter. M is the
   TurnOver menu, S the Settings window, K the keyboard style, H these guides. Any other key reads the list.
   Command Control M opens the menu in one press. The menu is short: This app, Settings, Keys, Tools, Help,
   Support TurnOver, Quit. Every setting lives in the Settings window, in sections down the side.
2. Command Control Period turns TurnOver off and on, from anywhere. Off, VoiceOver reads as usual.
3. Command Control Shift T gives the app in front to VoiceOver, or back to TurnOver, and remembers it.

Everything else is the keys of the screen reader you already know. See The TurnOver layer.

Choose your keys

TurnOver speaks three screen readers' keys. Press Command Control Comma, then K, until you hear the one you want:

- VoiceOver keys (the Mac style). Every key. VO is Control and Option together (or Caps
  Lock); VO arrows move, VO Space presses, VO Shift Down goes into things, VO U is the rotor.
- NVDA keys (the Windows style). Every key. Caps Lock is the NVDA key; Caps Lock L reads
  the line, Caps Lock A reads to the end, Caps Lock F7 lists the links and headings, H and K jump by heading and link
  on a web page.
- JAWS keys. Every key. JAWS's laptop layout: Caps Lock U, I and O for lines, J, K and L for
  words, Caps Lock Z for the virtual cursor, Caps Lock F6 and F7 for the lists.

The style changes which keys you press, never what TurnOver can do. Keyboard styles explains the
differences and how the three fit on a Mac keyboard.

Reading

Arrow through text, documents, web pages and messages; say all reads to the end and stops where you were. In a web
page or a message, single letters jump by heading, link, button or form field, and Return or Space presses. See
Reading and say all.

The apps

TurnOver reads every app. For the ones people use most, it adds keys and reading of its own: Mail, Messages and
WhatsApp, Word and Excel, Safari, Music, Podcasts, Calendar, Pages, Numbers, Keynote, Terminal, Steam and more.
Each app's own keys are listed at the end of the key pages, and described in The apps. An app that
VoiceOver does better can stay VoiceOver's: Command Control Shift T.

When something isn't read well

- Screen recognition (Command Control Comma, then R) reads a window from the screen itself, for apps that tell the
  Mac nothing about their windows.
- Plugins teach TurnOver an app: its names for things, its keys, what to read. Anyone can write one, as data, no
  programming needed, and share it. See Plugins.
- Give the app to VoiceOver with Command Control Shift T.

Help and problems

- Keyboard help: the TurnOver menu, Keys, then keyboard help: every key says what it does without doing it.
- Every shortcut here: Command Control Comma, then Slash: the keys that work where you are, in a list.
- Something wrong: Troubleshooting and feedback. Reports go through GitHub,
  where everyone can see and help with them.
- What TurnOver does with your data: Privacy and security.

TurnOver is free and open source, made in spare time. The code, the plugins and the ways to help are at
github.com/TurnOver-For-Mac/turnover.


GETTING STARTED

TurnOver is a screen reader for the Mac. It uses VoiceOver's keys, so what you already know works, and it reads
the apps you use every day more simply than VoiceOver does. It runs on macOS 14 or later, on Apple silicon and Intel.

Installing

1. Move TurnOver to your Applications folder and open it. A welcome message explains what it needs.
2. Turn TurnOver on in System Settings, Privacy and Security, under Accessibility (called Device Control and
   Data Access on macOS 27) and under Input Monitoring. macOS asks for the first; if it doesn't ask for the
   second, TurnOver tells you where it is.

Starting and stopping

- Command Control Period starts TurnOver, or stops it, from anywhere. A rising chime means on, a falling one off.
  When TurnOver stops, VoiceOver takes over.
- Command Control Shift T gives the app in front to VoiceOver, or back to TurnOver, and remembers it. TurnOver
  reads every app unless you give one to VoiceOver. TurnOver reads password fields and macOS's own prompts too, and
  never says what you type in a password field.
- To start TurnOver when you log in: the TurnOver menu, Settings, Starting, Open TurnOver at login.

The first five minutes

- Press Command Control Comma. TurnOver says "TurnOver": press M for the TurnOver menu. Up and Down move,
  Right or Return opens, Escape closes.
- Press Command Control Comma twice to hear every letter you can press after it.
- Your VoiceOver voice, speed and verbosity can come with you: the TurnOver menu, Settings, Copy VoiceOver settings, then Copy. Revert, beside it, puts back what you had before.

Updates

TurnOver checks once a day. When there is a new build it says so and asks whether to install it. The TurnOver menu,
About and updates, Updates checks now; What's new lists every build's changes.


THE TURNOVER LAYER

TurnOver keeps its own commands behind one key, so it never takes a shortcut away from your apps: press
Command Control Comma, hear "TurnOver", then press a letter. It works in every app, including ones VoiceOver reads.

The letters

  Letter: What it does
  M: The TurnOver menu
  S: The Settings window: every setting, sections down the side
  T: Switches the app in front between TurnOver and VoiceOver, and remembers it (also straight away: Command Control Shift T)
  D: Direct: every key goes straight to the app in front and neither TurnOver nor VoiceOver says anything there, for a game or app that speaks for itself. Command shortcuts (Command Tab, Command Q) still work. D again to leave; remembered
  A: Who reads: TurnOver in its apps, TurnOver everywhere, or VoiceOver everywhere
  V: Copies your VoiceOver settings: voice, speed, pitch, verbosity
  K: Goes round the keyboard styles: VoiceOver keys, NVDA keys, JAWS keys
  J: "That was wrong": marks this moment for your next feedback report
  H: This guide
  I: Describes the picture under TurnOver's cursor
  C: Copies the last thing TurnOver said
  G: Trackpad gesture control on or off (experimental)
  R: Screen recognition: reads a window from the screen itself
  Slash: Every shortcut that works where you are, in a list; Return runs one

Any other key says the list again. Escape, or three seconds with no letter, cancels.

Command Control Period

A single press starts or stops TurnOver from anywhere, even if TurnOver has stopped answering: a small helper,
TurnOver Key, listens for it from login.

The TurnOver menu

- This app: who reads the app in front, and that app's own commands. Apps whose support is new say
  "experimental support".
- Settings: speech (with the say all voice), keyboard, braille, documents, web pages, sounds, and Experimental.
- Apps: which apps TurnOver reads.
- Keys: every shortcut, keyboard help, and your own keys.
- Send feedback, About and updates, Quit.

In the menu, Right or Return opens a submenu or changes a setting; on a number (rate, volume) Left turns it down.
Settings that restart TurnOver change only with Return.


READING AND SAY ALL

Web pages and messages

Web pages and email messages are read as a document. Up and Down go line by line; Option with the arrows, word by
word. Single letters jump: in the Mac style, VoiceOver's Quick Nav letters (H heading, L link, F text field, T table,
1 to 6 headings by level); in the Windows style, NVDA's. TurnOver Space switches between reading the page and
typing into it. Enter activates a link or button.

Say all

Say all reads from where you are to the end: VO A in the Mac style, Caps Lock A in the Windows
style (Caps Lock Down Arrow with the desktop keyboard layout). It moves the caret as it goes.

- Any key stops it, and the caret is left on the word you had reached, not the start of the paragraph.
- Up and Down during say all skim: they move a line and carry on reading from there.

The say all voice

Say all can read in a natural voice made on your Mac, while everything else (moving, typing, menus) stays in your
usual voice, which answers at once. The TurnOver menu, Settings, Speech, Say all voice: "Same as speech", or a
natural voice. Natural voice speed is there too.

The natural voice reads ahead: while one paragraph plays, the next ones are being made, so it never waits.
Natural voices speak English for now; other languages keep your Mac's voices.

Documents

In Word, Pages and TextEdit, the arrows read as they move. VO Command H goes to the next heading (Shift for the
previous). In Pages, a table's line says its size; VO Shift Down reads it cell by cell (the arrows move, each
cell said with its row or column heading), and VO Shift Up or Escape comes back. Comments and highlights are
said after the line that holds them. TurnOver says the page as you move onto it.

PDFs in Preview (experimental)

A PDF is read like a web page: line by line across pages, with "page 2 of 5" as you reach each page, and headings
by H. Highlights, notes and text boxes, which Preview hides from VoiceOver, are read where they sit.


THE APPS

What TurnOver adds in each app it reads. To give an app to TurnOver or back to VoiceOver: Command Control Comma, T.

Mail

Up and Down move through the messages; Home and End go to the first and last. The message is read as a document.
Tab goes from the list to the message, Shift Tab to the mailboxes. Command Shift D sends, and TurnOver says "sent".

Messages and WhatsApp

The keyboard stays in the message box. Shift Tab goes up to the messages, newest first; Up and Down move; the
shortcut menu (VO Shift M) lists a message's actions; Escape goes back to the box. Command Control 1 to 9 read the
latest messages from anywhere, 1 the newest. New messages are read as they arrive.

Music, Podcasts and TV

Up and Down move through the page, shelf by shelf; Left and Right jump between shelves; Return plays; Space pauses
and says which.

The App Store

Up and Down move through every app and button; Left and Right between shelves. Return opens an app's page; Space
presses its own button (Get, Open, Update). Command F searches.

Microsoft Word and Excel

Word reads as you move, says the page as you reach it, and has VoiceOver's keys for headings, tracked changes and
spelling errors (VO Command H, R, E). Tables say each cell with its headings. In Excel, cells are read as you move.

Calendar (experimental)

Read as a diary, in day, week and month view: Left and Right a day at a time, with its number of events; **Up and
Down through that day's events, the time first; Option Up and Down a week at a time; Return** opens an event.
Command T goes to today.

Pages, Numbers and Keynote (experimental)

- Pages: headings by VO Command H, tables cell by cell with VO Shift Down, comments and highlights read in
  place, the page said as you reach it.
- Numbers: an arrow on an empty sheet goes into its first table; moving says each cell with its column's or
  row's heading ("Sales, 1521"); VO Command T and Shift T go between tables.
- Keynote: moving between slides reads the slide, title first, with its notes when they are showing. While a
  presentation plays, each slide is read as you move (macOS asks once whether TurnOver may control Keynote).

Terminal

New output is read as it arrives; your own typing isn't read twice. TurnOver Up and Down review earlier lines.

Steam

Steam's Big Picture is read as you move, once you turn it on: Settings, Other apps' speech, Read Steam's Big Picture (or the TurnOver menu, Games), then Restart Steam there. It's
off to begin with because reading it makes Steam open a debugging port on your Mac while Steam runs, which other
programs on the same Mac could use too; turning it off, or uninstalling TurnOver, removes that again. Games that
support it speak through TurnOver without any of this.


KEYBOARD STYLES

TurnOver speaks three screen readers' keys. Press Command Control Comma, then K, until you hear the one you want; the
TurnOver menu, Settings, Keyboard, and the Settings window offer the same choice. The style changes which keys you
press, never what TurnOver can do.

VoiceOver keys (the Mac style)

VoiceOver's own keys, doing what they do in VoiceOver. VO is Control and Option together; Caps Lock works as VO too.
VO arrows move around, VO Space presses, VO Shift Down and Up go into and out of things, VO U is the rotor, VO M the
menu bar, VO D the Dock, VO Shift M the shortcut menu. VO Command Shift with the arrows changes speech settings, VO
Command with the arrows moves by the rotor's kind. Control pauses speech. One Quick Nav is shared with VoiceOver.

Every key, VoiceOver keys.

NVDA keys (the Windows style)

NVDA's own keys, doing what they do in NVDA. Caps Lock is the NVDA key (Control and Option works too): Caps Lock N
the TurnOver menu, Caps Lock 1 keyboard help, Caps Lock L the current line, Caps Lock A say all, Caps Lock F7 the
elements list, Caps Lock Space browse mode on and off. Control stops speech. Where NVDA uses Alt, TurnOver uses the
Mac's Command key, which sits where Alt does on a PC keyboard. The role is said before the words, as NVDA says them.

Every key, NVDA keys.

JAWS keys

JAWS's laptop layout, with Caps Lock as the JAWS key. The reading grid: Caps Lock U, I and O for the previous, current
and next line; J, K and L for words; M, Comma and Period for characters; Y, H and N for sentences; Control U, I and O
for paragraphs. Caps Lock Shift J and L read the line up to and from the cursor. Caps Lock Z is the virtual cursor,
Caps Lock F5, F6 and F7 the lists of form fields, headings and links, Caps Lock Semicolon the PC cursor and Caps Lock P
the JAWS cursor, Caps Lock 8 and 9 click. During say all, Left and Right go back and on a sentence, and Page Up and
Page Down change the speed for that say all. Every other key is NVDA's.

Every key, JAWS keys.

On a Mac keyboard

- Insert doesn't exist, so every Insert, NVDA or JAWS key chord becomes Caps Lock.
- The Mac's own shortcuts win. Where a Windows reader's key collides with a Mac shortcut (Command Comma opens
  every app's settings, Command Period cancels), the reader's command sits on a second key, listed on its page.
- Windows' Control is often the Mac's Command for app shortcuts: copy, find, new tab. In screen reader chords it
  stays Control.
- Home, End, Page Up and Page Down are Fn with the arrows on a laptop keyboard. F1 to F12 need Fn unless the Mac
  is set to use them as standard function keys.

In every style

- TurnOver's own commands behind Command Control Comma never change with the style.
- Keyboard help (the TurnOver menu, Keys) says what any key does without doing it.
- Command Control Comma, then Slash, lists every key that works where you are.
- Your own keys (the TurnOver menu, Keys, My own keys) sit on top of any style.


TROUBLESHOOTING AND FEEDBACK

TurnOver stops answering

VoiceOver comes back by itself within a few seconds, and your keys work again; if TurnOver is still stuck, it
restarts itself. Command Control Period stops or starts it from anywhere.

No sound at all

If even VoiceOver is silent, macOS's sound service may have stopped. In Terminal, run this and type your password:

    sudo killall coreaudiod


Or restart the Mac. Then press Command Control Period to start TurnOver.

Force quit, spoken

Command Option Escape lists the running apps: choose one, then force quit it, ask it to quit, or cancel.

Sending feedback

- The moment something goes wrong: Command Control Comma, J marks it, and you carry on.
- When you're ready: the TurnOver menu, Send feedback. A report is saved to your Desktop, and TurnOver's problem form
  opens on GitHub with your build and Mac filled in. Say in a sentence what you were doing and what you expected, and
  drag the report in if you like. Reports on GitHub are public: choose the report without what TurnOver said if
  anything private was on screen.
- To ask for an app: switch to it, then the TurnOver menu, This app, Ask for it to be tuned. The request form opens
  on GitHub, filled in with how the app is built (never what's in it).
- You need a free GitHub account to post. TurnOver is a spare-time project: every report is read, but replies may
  take a while.

Removing TurnOver

The TurnOver menu, About and updates, Uninstall TurnOver: the app only (your settings kept), or everything
(settings, logs, permissions and login items), which also turns VoiceOver on and removes anything an earlier TurnOver put into VoiceOver's settings.


PRIVACY AND SECURITY

A screen reader has to see everything on your Mac and hear every key, so it asks for macOS's most powerful
permissions. This page says what each is for, what never leaves your Mac, and how you can check for yourself.

The permissions, and why

- Accessibility: to read apps, windows and controls, and to move and press them for you. Every screen reader
  needs it.
- Input Monitoring: to hear TurnOver's keys (VO keys, the TurnOver layer, quick navigation). TurnOver looks at a
  key to see whether it is one of its commands; anything else goes straight on to the app.
- Screen Recording: only for screen recognition and describing a picture, when you ask. Both run on your Mac.
- Automation (asked once, for one app at a time): for example Keynote, to read a slide while a show plays.

TurnOver does not ask for Full Disk Access.

What leaves your Mac

TurnOver connects to one place by itself: its update site, `doll-eye.github.io/turnover-updates`, to check for a
new build. Nothing about you or what you do is sent: it only fetches that file.

Everything else happens on your Mac:

- Speech, including the natural say all voice, is made on your Mac.
- Screen recognition and picture descriptions use Apple's on-device recognition and model.
- Game speech listens only on this Mac (it accepts nothing from the network), and never speaks over Apple's apps or a
  browser. Reading Steam's Big Picture is off until you turn it on, because it makes Steam open a debugging port on
  this Mac while it runs; turning it off, or uninstalling TurnOver, removes that again.

Things you choose to send, and see before they go:

- Send feedback saves a report on your Desktop and opens TurnOver's problem form on GitHub in your browser. You
  write the report yourself, and attach the file only if you choose to; TurnOver never sends anything on its own.
  Reports on GitHub are public.
- Ask for this app to be tuned opens the request form on GitHub, filled in with how the app is built (kinds of
  item and counts, never what is in it), for you to post.

Check it yourself

You don't have to take our word for it. Install a firewall that shows every connection, such as LuLu (free, from
objective-see.org) or Little Snitch, and use TurnOver as usual. You will see TurnOver contact its update site, and
nothing else.

What TurnOver keeps

TurnOver keeps a log on your Mac, in your Library folder: Application Support, TurnOver, logs. Logs older than 30
days are deleted.

- The log records what TurnOver did: the app, the kind of item, the command a key ran.
- It never records what you type. A typed key is written as "a typed key", never the key itself.
- It doesn't record the words you were reading. Where a name, a page or a message would appear, the log keeps only
  how many characters it had.

The log is plain text: you are welcome to open it and read it.

A feedback report holds these logs. "Send a report with what TurnOver said" also includes what TurnOver said aloud in
the last 15 minutes, which can be the text of an email or page you were reading; "Send a report without what
TurnOver said" leaves it out. Either way the report is a file on your Desktop: you decide whether to attach it, and
since GitHub reports are public, choose the one without what TurnOver said if anything private was on screen.

Who can talk to TurnOver

TurnOver's own helpers (its Settings window, the Command Control Period helper, the plugin tool, Windy) reach it
through a private channel in TurnOver's own folder. Before anything is read, macOS checks that the program on the other
end is signed by TurnOver's developer; any other program is turned away and the refusal is logged. A copy you build
yourself without a developer certificate accepts only the programs inside its own app. Like any app's, TurnOver's
settings file can be changed by programs running as you; a script you give a key to asks you before it first runs.

Apps that speak through TurnOver

An app can ask TurnOver to speak for it (a game, for example), through a port on this Mac only. TurnOver works out
for itself which program is asking (from the Mac's own records, not from what the app says), and the first time asks
you, by name, whether you trust it. An app you allow is heard only while it is the app in front, and it can do nothing
but speak: no settings, no keys. Settings, Apps that speak through TurnOver, lists them and changes your answer.

Passwords and security prompts

One reader speaks at a time: TurnOver while it is on, VoiceOver while TurnOver is off.

- Typing into a password field is never spoken or logged by TurnOver, even where an app hides that the keyboard
  is in one. TurnOver counts the characters instead.
- macOS's own prompts (an administrator password, the keychain, Touch ID, "Allow" questions): TurnOver reads the
  prompt when it opens and puts you in it, and takes you back to your app when it closes.
- If you would rather Apple's own reader handled a prompt, turn TurnOver off with Command Control Period: VoiceOver
  comes on if you have set it to, or press Command F5.

When we get something wrong

We'll say so here and in What's new.

- 18 October 2026: in Kindle's Amazon sign-in, TurnOver read the password aloud as it was typed, because the page
  told TurnOver the keyboard was somewhere other than the password field. It was found the same day and fixed for
  every app: typing into a password field is never spoken or logged, wherever the app says the keyboard is. It
  needed an app that hides where the keyboard is, as Kindle's sign-in does; Kindle support was new that day, so we
  know of no released build where it happened.

Questions

Ask on TurnOver's GitHub page (github.com/TurnOver-For-Mac/turnover), from the TurnOver menu, Send feedback. Something that
could expose what a person reads or types is best reported privately, through the repository's Security tab.

NVDA KEYS: EVERY KEY

This page is made from TurnOver's own command tables (`turnover-coretest --keys-reference`, 21 Oct 2026), so it matches the build it came with. Don't edit it by hand.

The NVDA keys style (the Windows style): NVDA's own keys, doing what they do in NVDA. TurnOver in a key means the NVDA key: Caps Lock, or Control and Option together. NVDA's Alt is the Mac's Command key, by position. Keyboard help (the TurnOver menu, Keys) says what any key does without doing it; Command Control Comma, then Slash, lists the keys that work where you are.

Switch styles with Command Control Comma, then K. TurnOver's own commands behind Command Control Comma are the same in every style: see The TurnOver layer.

PLUGINS

A plugin teaches TurnOver an app: what to call its controls, which keys do what, what to read when something
changes, and what to keep quiet. Plugins are written as data, not code: a folder with a manifest and a few JSON
files. That means no programming, nothing a plugin can do behind your back, and anyone can read one before
installing it.

Using one

- The plugin library (the TurnOver menu, Tools, Plugins, Plugin library) lists the plugins others have made.
  Each one is checked and signed before it appears, and says what it does before you install it.
- Install from a folder or the clipboard, in the same menu, for one someone sent you.
- Reload plugins after editing one.

Making one

1. Switch to the app, then the TurnOver menu, Tools, Plugins.
2. Choose Write a plugin for this app yourself: TurnOver makes a starter folder with the guide, a snapshot of the
   app's window and its menus, so you can see what the app calls things.
3. Or choose Make a plugin with an AI: TurnOver gives it the window's labels, text and menus and its own log, with
   your typing and speech left out, and the AI writes the first draft. You read and change it.
4. Edit the files, then Install my plugin from its folder. Reload after each change.

The format is in the plugin guide: what a
manifest holds, how a rule names a control, how a key is given a command, and the checker that finds mistakes.

Sharing one

Plugins are shared through the plugins repository on GitHub: send yours as a pull request, where everyone can read
it. The checker runs on it, it is reviewed, and then the library's signed list carries it to everyone. The plugins
repository is at github.com/TurnOver-For-Mac/turnover-plugins.

What a plugin can't do

Run code, reach the internet, read anything in an app it doesn't name, or change TurnOver's settings. Those limits
are the point: a screen reader sees everything on your screen, and a plugin shouldn't widen that.
