# Tools in this demonstration

The [app index generator](build-demo-index.py) rebuilds APPS.md from the app records. It uses Python 3 and no added dependencies. Its --check option detects a stale index. It only operates inside this demo.

The [probe guide](turnover-probe/README.md) indicates where contributors would find diagnostic tooling. This tree does not include a working probe or add diagnostics to the reader build.
