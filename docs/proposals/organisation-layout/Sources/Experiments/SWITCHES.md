# Experiment switches and review decisions

This is a proposed registry, not the installed settings. No switch is changed here and no ownership defaults to Oliver.

Standalone probes need no production switch. A runtime experiment needs a verified independent switch, off by default for a new trial, and someone who has claimed the work. Select review for the relevant change.

Candidate areas from the original demo are FlatView, PageTree and Kokoro. Before a real trial, record the exact existing switch, current state, scope, owner, rollback and review date. Do not infer those facts from this layout.

At the review date, explicitly continue, graduate after validation, or retire. No automatic enablement or deletion occurs. Permanent diagnostic settings should be identified separately from experiments.
