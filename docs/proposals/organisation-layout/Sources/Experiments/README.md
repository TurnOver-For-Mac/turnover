# Shared experiments

These folders show how cross-app investigations could be organised. They do not establish the current state of those features in the real project.

- [CoExist](CoExist/RECORD.md)
- [FlatView](FlatView/RECORD.md)
- [Kokoro](Kokoro/RECORD.md)
- [PageTree](PageTree/RECORD.md)
- [ScreenInterface](ScreenInterface/RECORD.md)

Each investigation records who is working on it, its question, evidence and review date. Reviewers are chosen for the relevant change. Link affected apps to this single record. App-specific experiments remain with their app.

Read [switch rules](SWITCHES.md) and the [experiment template](../../docs/EXPERIMENT-TEMPLATE.md). These directories are excluded from default production builds; see [build boundaries](../../docs/BUILD-BOUNDARIES.md).
