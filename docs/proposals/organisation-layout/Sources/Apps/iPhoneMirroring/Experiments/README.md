# iPhone Mirroring experiments

These are summaries of earlier work for the layout demo. They do not contain runnable diagnostics or introduce new tests.

## Completed investigations

1. [Mac accessibility tree](2026-10-29-mac-accessibility-tree.md): window controls were exposed, but usable phone content was not.
2. [Developer service over USB](2026-10-29-developer-service-usb.md): Calculator controls and two button tests worked on the unlocked phone.
3. [Developer service over the network](2026-10-29-developer-service-network.md): discovery succeeded; socket opening failed before accessibility communication.
4. [Phone VoiceOver keyboard trials](2026-10-29-phone-voiceover-keyboard.md): both trials produced no response.

## Constraints and unanswered questions

- [Mac VoiceOver reading question](to-try-voiceover-on-the-mac.md): separate and unverified.
