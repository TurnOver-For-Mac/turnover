# Claiming work

Use one field in the app record: Being worked on. Put a person's name and an active issue link there, or Unclaimed. The generated index reads that field; do not maintain a competing assignment list.

This records current work, not a lifetime maintenance obligation. Choose reviewers per pull request. Shared changes need someone familiar with the affected area to review them.

Unknown responsibility never defaults to Oliver. Record AI assistance separately from the person accountable for the change.

An experiment also records who is working on it and when its next decision is due. At review, explicitly continue, graduate or retire it; a date alone never enables or deletes code.

For the proposed reorganisation, use one migration lead to coordinate the file map and sequence, with independent review. See the [team proposal](docs/CODEX-REPLY.md).
