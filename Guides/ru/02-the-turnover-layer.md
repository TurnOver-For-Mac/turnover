# Слой TurnOver

TurnOver держит свои команды за одной клавишей, чтобы никогда не отбирать сочетание у приложений: нажми **Command Control запятую**, услышь «TurnOver», затем нажми букву. Работает в любом приложении, в том числе в тех, которые читает VoiceOver.

## Буквы

| Буква | Что делает |
|---|---|
| M | Меню TurnOver |
| S | Окно настроек: все настройки, разделы по бокам |
| T | Переключает приложение в фокусе между TurnOver и VoiceOver и запоминает выбор (то же сразу: Command Control Shift T) |
| D | Прямое управление: каждая клавиша идёт прямо в приложение в фокусе, и ни TurnOver, ни VoiceOver там ничего не говорят — для игры или программы, которая сама себя озвучивает. Сочетания Command (Command Tab, Command Q) продолжают работать. Ещё раз D — выйти; запоминается |
| A | Кто читает: TurnOver в своих приложениях, TurnOver везде или VoiceOver везде |
| V | Копирует настройки VoiceOver: голос, скорость, высоту, подробность |
| K | Перебирает клавиатурные стили: клавиши VoiceOver, NVDA, JAWS |
| J | «Это было неправильно»: отмечает момент для следующего отчёта об ошибке |
| H | Это руководство |
| I | Описывает картинку под курсором TurnOver |
| C | Копирует последнее, что сказал TurnOver |
| G | Управление жестами трекпада включить или выключить (экспериментально) |
| R | Распознавание экрана: читает окно с самого экрана |
| Косая черта | Все сочетания, которые работают там, где ты сейчас, списком; Return запускает одно из них |

Любая другая клавиша говорит список ещё раз. Escape или три секунды без буквы — отмена.

## Command Control точка

Одно нажатие запускает или останавливает TurnOver из любого места, даже если TurnOver перестал отвечать: маленькая вспомогательная программа, TurnOver Key, слушает эту клавишу с момента входа в систему.

## Меню TurnOver

- **Это приложение:** кто читает приложение в фокусе и собственные команды этого приложения. У приложений, поддержка которых только появилась, написано «экспериментальная поддержка».
- **Настройки:** речь (вместе с голосом для «Читать всё»), клавиатура, брайль, документы, веб-страницы, звуки и «Экспериментально».
- **Приложения:** какие приложения читает TurnOver.
- **Клавиши:** все сочетания, справка по клавиатуре и свои собственные клавиши.
- **Отправить отзыв, О программе и обновления, Завершить.**

В меню вправо или Return открывает подменю или меняет настройку; на числе (скорость, громкость) влево убавляет. Настройки, которые перезапускают TurnOver, меняются только по Return.
