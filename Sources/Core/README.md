# Shared reader code

Core holds behavior shared across apps. Every Swift file here still compiles into the existing TurnOverCore target with its main-actor default. Filenames, types and call sites have been retained.

## Finding a responsibility

| Folder | Main responsibility |
| --- | --- |
| [Accessibility](Accessibility/) | Accessibility events, focus changes and bounded walks |
| [Braille](Braille/) | Reader-side braille state, translation requests, input and output |
| [BrowseMode](BrowseMode/) | Browse commands, selection, activation and focus-mode policy |
| [Keys](Keys/) | Gesture and script resolution, keyboard styles, rotor and trackpad input |
| [Lifecycle](Lifecycle/) | Reader ownership, coexistence policy and wake restoration |
| [Objects](Objects/) | Accessible objects, controls, navigation, find and choosers |
| [Plugins](Plugins/) | Data plugins, recipes, profiles and named parts |
| [ScreenRecognition](ScreenRecognition/) | Existing recognition and description paths |
| [Settings](Settings/) | Configuration, profiles, settings bridge and VoiceOver import |
| [Speech](Speech/) | Words, formatting, speech requests, tones and ducking |
| [Support](Support/) | Logging, feedback, paths, helpers, requests and synchronization |
| [Text](Text/) | Text ranges, editing, spelling, formatting and clipboard announcements |

[Core.swift](Core.swift) coordinates the reader; [API.swift](API.swift) and [AppModule.swift](AppModule.swift) define shared entry points. [Edition.swift](Edition.swift) describes the build. [EmbeddedResources.swift](EmbeddedResources.swift) is generated by [make-embedded.py](../../make-embedded.py): edit the source JSON in Resources, never the generated file.

## Ownership and boundaries

The folder names do not change actor isolation. Speech playback remains in [TurnOverSpeech](../TurnOverSpeech/), braille drivers on the thread in [TurnOverBraille](../TurnOverBraille/), and the keyboard tap in [TurnOver](../TurnOver/). Preserve their existing queues, locks, callbacks and teardown rules in [AGENTS.md](../../AGENTS.md).

Reusable reading models live in [Views](../Views/README.md); concrete app behavior lives in [Apps](../Apps/README.md); native Mac integration lives in [System](../System/README.md). Existing cross-area dependencies remain, including Core calls into app helpers. Separating those dependencies requires its own behavior and interface review.

The [source map](../README.md) explains source discovery and exclusions. Tests stay in [TurnOverTests](../TurnOverTests/) and [Tests/Fixtures](../../Tests/Fixtures/); moving a responsibility does not move or silently register its tests.
