# Check Spotify playback shortcuts

1. Open the Spotify desktop app with TurnOver active. Play a track, move focus out of any text field, and use the TurnOver key and Space to switch to focus mode if needed.
2. Press Command Down and Command Up. Spotify lowers or raises its playback volume and TurnOver says “quieter” or “louder” once per shortcut. The cue also plays at the corresponding volume limit.
3. Press Command Left and Command Right. Spotify receives the previous and next commands, and TurnOver says “previous track” or “next track”.
4. Focus Spotify's search field and type a few characters. Press Command Left and Command Right to move the caret to the start and end of the text. Command Up and Command Down leave the volume alone in this field.
5. Leave the search field and switch to browse mode. Command Up and Command Down move to the top and bottom of the document. Command Left and Command Right move to the start and end of the line.
6. Switch back to focus mode outside a text field and repeat a playback shortcut to check that its cue is available again.
