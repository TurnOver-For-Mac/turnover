# Check Zoom's meeting window

Use a test meeting, with a second participant where a step says so. TurnOver active, Mac keys.

## Zoom's own keys

1. Press Command Shift A. Zoom mutes or unmutes and TurnOver says "muted" or "unmuted" once. Press it again and hear the other word.
2. Press Command Shift V. TurnOver says "video on" or "video off" once, matching the camera.
3. Press Option Y. TurnOver says "hand raised". Press it again: "hand lowered".
4. Press Option Command 5. TurnOver says "sent" and the thumbs up.
5. While the other participant talks, press Command Shift 2. TurnOver says their name and "is speaking". In silence it says "No one is speaking". Focus stays in the meeting window.
6. Press Command 2. Zoom's own key works as before and TurnOver adds nothing.
